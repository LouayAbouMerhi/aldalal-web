# Better product photos (optional)

Drop image files here named after the product id to replace the small photo that came
from the Excel sheet, for example:

    data/photos/colgate-advanced-white-toothpaste-75ml.jpg

The id is the last part of a product page URL. `.jpg`, `.png`, `.webp` and `.avif` work,
and bigger is better — 1000px or more gives a sharp zoom.

Then run `npm run import` again.
